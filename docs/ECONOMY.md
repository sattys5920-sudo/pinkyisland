# 핑키 디저트 아일랜드 · 경제 설계와 전체 가격표

## 설계 기준
- **활동별 목표 시급** (집중해서 1시간 했을 때 벌리는 골드)
  - 시작 구역 ≈ 2,000G/h: 사탕 연못 낚시, 먼지 숲 전투, 광산 입구 채굴
  - 중간 구역 ≈ 4,000G/h: 등대 해변 낚시, 깊은 먼지 숲·해식 동굴 전투, 별빛 언덕(밤)
  - 후반 구역 ≈ 7,000G/h: 해식 동굴 낚시, 의문의 동굴 전투+채굴
  - 텃밭(방치 수익) ≈ 칸당 120G/h. 3분짜리 작물은 계속 물을 줘야 해서 칸당 500G/h.
- **낚시**: 입질까지 5~12초, 한 마리에 약 30초 → 시간당 약 120마리. 별 등급 평균 ×1.29.
- **전투**: 몬스터는 25초마다 한 마리씩 다시 나타나요. 처치 골드 = 공격력×(0.8~1.2) + 전리품 판매가.
- **채굴**: 바위는 구역마다 6~8개, 20분마다 다시 생겨요. 희귀도별 평균가 ◆35 / ◆◆130 / ◆◆◆500 / ◆◆◆◆1,500 / ◆◆◆◆◆5,000.
- **판매 보정**: 전문 상인 +15~25%, 친한 친구 +10%, 오늘의 시세 70~140%(인기 품목 2배), 같은 물건 많이 팔면 1개마다 −3%.
- **소비처 기준**: 옷 한 벌(상의+하의+신발) ≈ 시작 구역 1시간, 세트 ≈ 1~2시간, 무기는 그 티어 시급의 2~6시간, 텃밭 확장은 다음 티어로 넘어갈 때쯤.
