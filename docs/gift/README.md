# 플레이어 선물 (12월 말에 이어서)

같이 플레이한 사람들에게 주는 선물. **한 사람에게 카드 다섯~여섯 장**이 오고, 하나씩 뒤집으면 그 게임에서 그 사람이 한 일이 나온다. 다 뒤집으면 마지막 장("세계마다 이름은 달랐지만 모두 한 사람이었어요")이 열린다.

- 확정 시안: `cards-draft.html` (예시: 하니·예지·다니엘·해린·사나 = 한 사람) · 아티팩트 https://claude.ai/artifact/M5ix34CGqsHCMxCNkrvhG3
- 처음 비교한 시안 5개: `five-drafts.html` · https://claude.ai/artifact/WJ1G9NcSCsgmj31XrbASj9
- 지금 카드 안의 숫자·칭호·한마디는 전부 지어낸 예시. 이름(약초·기숙사·주민·역할)만 각 게임 코드에서 가져옴.

## 사람 잇기

**짝 표는 비공개 페이지에 있다 (공개 저장소에는 안 올림):** https://claude.ai/artifact/5MnnG4ok9iiqYwFQRrPnjq · 1번 사람 카드 시안(실제 기록 4장): https://claude.ai/artifact/QVvc8HgiUuPRmxncPAPWXA

게임마다 계정이 따로라서 자동으로 못 잇는다. **운영자가 게임별 닉네임 표를 준다** (아이디 몰라도 됨, 여섯 게임 모두 닉네임이 저장돼 있음).

```
부를 이름: 괴이=..., 아르카눔=하니, 신당=예지, 투명인간=다니엘, 핑키=해린, 별빛=사나
```
안 한 게임은 빼고, 모르는 칸은 비워 두면 데이터에서 닉네임 목록을 보여 주고 고르게 한다. 같은 게임 안 닉네임 중복·닉네임 변경은 따로 확인.

## 정한 것

- **넣지 않음**: 별빛 소원나무·타임캡슐(개인적인 내용), DM·채팅 내용(다른 사람 말이 섞임 → 횟수 정도만), 비밀번호 등 로그인 정보로 사람 맞추기.
- 사람마다 추측할 수 없는 링크. 검색 안 잡히게 `noindex`.

## 게임별로 꺼낼 수 있는 기록 (코드 기준)

- **아르카눔**: 기숙사(G/R/H/S), 약초 도감 `herbFarms/{playerId}.dex` = 약초 id → **처음 발견 시각만** (수확 개수는 저장 안 됨 → "제일 많이 모은 약초"는 불가, 대신 도감 수·가장 귀한 약초·**학교 최초 발견자**는 가능), 리더보드, 금지된 숲, 퀴디치, 기숙사컵, 최종 추리.
- **신당**: 호령(알 번호 `companions/{playerId}.eggId`), 임무 1~5일 채팅 참여, 식혼 토벌, 객잔 미니게임(윷놀이·투전·장기·야바위), 살생부 응답, 혼록 구슬. 주인공 NPC: 달이·막순·재희·은실·수진.
- **투명인간**: 역할(01 반장 ~ 14 뒷자리), 날마다 미션 성공/실패, 거래, 쪽지, 피드 글.
- **괴이**: 계정·플레이어·피드 정도 (README상 목업 — 실제 플레이 기록이 있는지 확인 필요).
- **핑키**: `players/<uid>` 기록(요리·전투·돈·생활·도감·리조트 등, 관리자 기록 순위 탭과 같은 집계), 집터·지붕, 주민 호감도, 다크 보스, 콩이 방 단서, 본 엔딩, 축제.
- **별빛**: 기숙사(듀모른·엠버킬른·더스크폴드 …), 물약, 수업 지식, 시험, 마법 생물, 시장.

## 12월에 할 순서

1. 닉네임 표 받기
2. 데이터 내보내기
   - 핑키·별빛: 콘솔 > Realtime Database > ⋮ > JSON 내보내기
   - 나머지 넷(Firestore): 내보내기 스크립트를 만들어 서비스 계정 키로 한 번 실행
3. 사람별로 묶고 칭호·한마디 쓰기
4. 사람별 페이지 생성 → 링크 나눠 주기
