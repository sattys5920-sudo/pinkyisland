# 다크 보스 패턴 엔진 (보리 ~ 콩이)

토리는 `index.html` 안의 예전 코드(토리???)를 그대로 써요. 나머지 11 명은 주민마다 `public/bosses/<주민>.js` 하나에 보스 그림 · 기본 공격 · 패턴 7 개 · 움직일 때 연출 · 50% 변신 연출을 모두 넣어요. 기획은 `docs/DARK_STORY.md` 의 "보스 패턴 규칙 · 겹침 방지 목록" 을 그대로 따라요.

## 모듈 모양

```js
import { pick, beat, warnCircle, inEll, ... } from './kit.js';
export default {
  reach: 120,        // 칼이 닿는 거리 (보스 발 위치에서) · 기본 110
  height: 170,       // 이름표를 그릴 높이 (발에서 위로)
  pos(B){ return [x, y]; },              // 보스 발 위치. B.now · B.t · B.bs 만으로 정해요 (모두에게 같아야 해요)
  tick(B, dt){},                         // 매 프레임, 방 안 모든 사람 화면에서 (쓰러진 사람 · 호스트 포함)
  hitMul(B, x, y){ return 1; },          // 내가 (x, y) 에서 때릴 때 배수. 0 = 무적 ('팅'), 기본: 기절 중 2
  swing(B, cx, cy){ return false; },     // 칼을 휘두른 자리 (cx, cy). 물건을 쳤으면 true (보스는 안 맞아요)
  tap(B, wx, wy){ return null; },        // 화면을 누른 자리. {x, y, act} 를 돌려주면 그 자리로 걸어가서 act()
  chat(B, text){},                       // 이 방에서 채팅을 보냈을 때 (콩이 ⑥)
  drawFloor(B, c){},                     // 바닥 (사람 · 가구 아래) · 월드 좌표
  drawBody(B, c){},                      // 보스 몸 (발 y 로 앞뒤 정렬) · 월드 좌표
  drawTop(B, c){},                       // 사람 위 (날아가는 물건 · 사슬 …) · 월드 좌표
  drawScreen(B, c, w, h){},              // 화면 고정 (변신 연출 · 어둠 · 안개 · 화면 테두리) · CSS 픽셀
  label(B, c, x, y, t){},                // (선택) 이름표를 직접 그릴 때. 없으면 엔진이 '보리???' → 변신 뒤 '윤보혁' + 체력 줄
};
```

## B (엔진이 넘겨주는 것)

| 이름 | 뜻 |
|---|---|
| `B.npc` | 주민 id ('bori' …) |
| `B.r` | 방 기록 (`hp`, `max`, `bossAt`, `rageAt`, `lowAt`, `wipe`, `bs` …) |
| `B.bs` | 같이 쓰는 패턴 상태 (`r.bs`) · 쓰기는 `B.tx` 로만 |
| `B.now` | 서버 시각 ms (모두 같아요) |
| `B.t` | 보스전 시작부터 초 |
| `B.phase` | 1 (100~50%) · 2 (50~20%, 변신 뒤) · 3 (20% 아래) |
| `B.pt` | 지금 단계가 시작된 뒤 초 |
| `B.ph2`, `B.ph3` | 변신 · 20% 부터 초 (아직이면 -1) |
| `B.hpF` | 남은 체력 비율 |
| `B.W`, `B.H` | 방 크기 (1100 × 900) |
| `B.hx`, `B.hy` | 보스 집 자리 (방 가운데 550, 560) · 문은 (550, 800) |
| `B.all` | 방 안 사람 (uid 순) `{uid, x, y, down, nick, bp, me?}` |
| `B.alive` | 쓰러지지 않은 사람 |
| `B.me` | 나 (관리자가 지켜볼 땐 null) |
| `B.target` | 노리는 몸 (관리자가 정한 사람이 방에 없으면 살아 있는 사람 중 하나) |
| `B.targetNick` | 노리는 몸 닉네임 (없으면 '???') |
| `B.host` | 내가 uid 가 가장 작은 사람이면 true · 정해야 하는 일(누가 맞았나 · 패턴 결과)은 호스트만 `B.tx` 로 적어요 |
| `B.lo` | 이 방 기본 피해 (보리 120 … 콩이 320) · 피해는 `B.lo ~ B.lo + 200` 안에서 |
| `B.name`, `B.real` | '보리' · '윤보혁' |
| `B.ctl` | 이번 프레임 내 캐릭터 조작 (아래) |
| `B.view` | 카메라 (`cx`, `cy`, `zoom`, `w`, `h`) |

| 함수 | 뜻 |
|---|---|
| `B.hurt(n, key, {raw})` | 나에게 피해 n. 같은 key 는 한 번만 (60 초 기억) · 쓰러져 있으면 무시 · 엔진이 1.5 배 (lo+80 이상은 3.2 배) · 단계별 1 · 1.25 · 1.5 배를 곱해요. `{raw:1}` 이면 n 그대로 (배수 없이 정한 숫자) |
| `B.push(dx, dy, dist)` | 나를 (dx, dy) 쪽으로 dist 만큼 밀어요 |
| `B.tp(x, y)` | 나를 그 자리로 옮겨요 (되감기 · 끌려감) |
| `B.tx(fn)` | `r.bs` 바꾸기 (서버 거래): `fn(bs, r)` 가 새 bs 를 돌려주면 적혀요, `undefined` 면 그대로. **매 프레임 부르지 마요** (일이 생길 때만 · 0.3 초 넘게 간격) |
| `B.heal(n)` | 보스 회복 (한 번에 최대 5%) · 호스트만 부르기 |
| `B.sfx(kind, gap)` | 'warn' (예고) · 'slam' (쾅) · 'hit' · 'hurt' — 주민마다 다른 소리가 겹쳐요 |
| `B.say(text, ms)` | 보스 말풍선 (내 화면). 모두 같은 때에 부르면 모두 같이 봐요 |
| `B.fx(text, x, y, color)` | 떠오르는 글자 |
| `B.shake()` | 화면 흔들기 |
| `B.setBp(obj)` | 내 위치 정보에 작은 값 실어 보내기 (예: `{k:2}` 고른 열쇠) → 다른 사람 화면의 `B.all[i].bp` · 작게 |
| `B.rng(seed)` | 같은 seed 면 모두 같은 난수 함수 |
| `B.hash(v)` | 숫자 해시 |
| `B.toScreen(x, y)` | 월드 → 화면 CSS 픽셀 |

### B.ctl (내 캐릭터 조작 · 매 프레임 tick 전에 비워져요)

| 이름 | 뜻 |
|---|---|
| `lock: true` | 못 움직여요 (우리 · 잠듦 · 시전 중) |
| `speed: 0.5` | 걸음 배수 |
| `drift: [vx, vy]` | 초당 밀리는 속도 (물살 · 기울어진 바닥) |
| `slip: true` 또는 숫자 | 미끄러짐 (관성) · 숫자가 작을수록 더 미끄러워요 |
| `steer: 0.6` | 걸음이 저절로 휘어요 (라디안) |
| `noAtk: true` | 칼을 못 휘둘러요 (무기 빼앗김) |

## kit.js

`pick(B, P, {gap, trans})` 단계별 패턴 차례 · `beat(B, every)` 기본 공격 박자 · `warnCircle / warnRect / warnLine / sector / inSector / inEll` 예고와 판정 · `shadow / tint / darkness / text` 그리기 · `cl / lerp / ease / dist`.

## 규칙

- **모두에게 같은 장면**: 보이는 모든 것은 `B.now` · `B.t` · `B.pt` · `B.bs` · `B.rng(seed)` 로만 정해요. `Math.random()` 금지 (떠오르는 숫자 같은 장식은 괜찮아요).
- **피해는 내 화면에서 나만**: 각자 자기 위치로 맞았는지 보고 `B.hurt` 해요. 친구가 맞는 건 친구 화면에서.
- **위치로 정해야 하는 결과** (자리 셋에 셋이 섰나 · 누가 갇혔나)는 호스트가 정해서 `B.tx` 로 적고, 모두 `B.bs` 를 보고 그려요.
- **사람 수**: 1 명 ~ 8 명 모두 깰 수 있어야 해요. 셋이 필요한 패턴은 사람 수에 맞춰 줄여요 (혼자면 하나).
- **설명 글 금지**: 게임엔 "~하세요" 안내가 없어요. 예고 표시 · 소리 · 보스 대사(짧게) · 배경 단서로만.
- **순서**: 1 단계 패턴 ①②③ → 50% 변신 (5 초, 그동안 보스 무적) → 2 단계 ④⑤⑥ (⑤ 노리는 몸 · ⑥ 증거로 기절 = `bs.stun = now + 8000`) → 20% 아래 ⑦. 기본 공격은 패턴 밑에 계속 (50% · 20% 아래로 갈수록 자주).
- **때릴 틈**: 패턴마다 보스에게 다가가 때릴 수 있는 틈이 있어야 해요.
- **가볍게**: 폰에서 돌아요. 무거운 그림은 처음 한 번 캔버스에 그려 두고 `drawImage`.
- **글꼴**: "Dongle". 보스 대사는 한국어, 짧게.
- **파일**: `public/bosses/<주민>.js` (+ 그림이 크면 `public/bosses/<주민>_art.js`). `index.html` 은 고치지 않아요. 엔진에 필요한 게 있으면 따로 알려 줘요.

## 혼자 시험하기

`public` 을 복사해 `firebase-config.js` 의 apiKey 를 "YOUR_KEY" 로 바꾸면 혼자 보기 모드예요. 가입 뒤 브라우저 콘솔에서:

```js
const D = __pinky.dboss;
await D.start('bori', 0.9);          // 체력 90% 로 보스전 시작 (0.45 → 2 단계, 0.15 → 3 단계)
D.bot(1, {x:500, y:620});            // 친구 넣기 (bp, down 도 줄 수 있어요) · D.unbot(1)
await D.warp(12);                    // 12 초 앞으로
await D.set({bs:{}});                // 방 기록 바꾸기
D.me(550, 700); __pinky.swing();     // 내 자리 · 휘두르기
D.ctx(); D.ctl(); D.room(); D.hp();  // 지금 B · 조작 · 방 · 내 체력
```
