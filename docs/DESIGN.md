# 핑키 디저트 아일랜드 기획 메모

## 콘셉트
- 12~14인 협동 라이프 시뮬레이션 웹게임 (동숲/스타듀 느낌)
- 그림체: D안 "말랑 클레이" (시안: https://claude.ai/artifact/QqXcw5o5ZMKcRTtmuvHsTN)
- 세계관: 디저트 섬. 주민 NPC는 덩어리 모양 솜인형, 플레이어는 사람 비율에 가까운 말랑한 인형
- 몬스터: 먼지 뭉치(숲), 좀나방(광산)
- 콘텐츠: 소규모 농사, 전투, 낚시, 채팅, 채굴, NPC 대화와 호감도

## 캐릭터 만들기
- 피부 색 6, 머리 모양 10 (남: 숏컷/가르마/댄디컷/가운데 가르마/파마, 여: 단발/긴 생머리/포니테일/웨이브/똥머리)
- 머리 색 8, 눈 4, 옷 5 (+옷 색 8), 모자 5

## 첫 접속 흐름
1. 캐릭터 만들기
2. 닉네임 정하기 (중복 불가)
3. 지붕 색 고르기: 14색 선착순, 이미 고른 색은 잠김
   - 빨강, 주황, 노랑, 연두, 초록, 민트, 하늘, 파랑, 남색, 보라, 분홍, 코랄, 갈색, 회색
4. 집터 고르기: 14곳 중 빈자리를 직접 선택
5. 처음부터 집이 지어진 상태로 시작 (지붕 = 고른 색)

## 웰컴 팩과 튜토리얼
- 웰컴 팩: 텃밭 2칸 + 토마토 씨앗 2개
- 텃밭은 각자 집 앞에 두는 개인 밭
- 물뿌리개는 NPC '하나'에게 말을 걸어 받음
- 튜토리얼: 웰컴 팩 받기 → 집 앞에 텃밭 놓기 → 하나에게 물뿌리개 받기 → 토마토 심고 물 주기 → 첫 수확

## 구성
- Firebase Realtime Database + 인증(구글/게스트) + Hosting, GitHub Actions로 자동 배포 (README 참고)
- 토마토: 단계마다 물 1번, 30초 뒤 다음 단계 (씨앗 → 새싹 → 잎 → 꽃 → 열매), 수확 시 3개
- 다음 차례: 상점(모모), 낚시, 채굴, 전투, 호감도
